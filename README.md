## 🚀 IScript (iScript) v2.0

Язык программирования, который компилируется в JavaScript, но пишется как на человеческом. Создан для тех, кто устал от многословности TypeScript и хаоса JavaScript. Меньше букв, больше смысла. Строгая типизация, константы, классы в одну строку. Один раз написал — везде работает.

## 📦 Установка

### Шаг 1: Клонирование репозитория
git clone https://github.com/noyemkaren-ship-it/IScript.git
cd IScript

### Шаг 2: Установка зависимостей Python
pip install colorama pydantic

### Шаг 3: Настройка глобальной команды (опционально)
Для macOS:
bash dependency/macos.sh

Для Linux:
bash dependency/linux.sh

После этого команда iscript будет работать из любой папки.

### Шаг 4: Расширение VSCode
В поиске расширений введите: IScript Language Support
Установите — появится подсветка синтаксиса .is файлов.

### Шаг 5: Node.js зависимости (для серверных проектов)
Компилятор сам напомнит об этом в терминале, но лучше сделать сразу:
npm init -y && npm install express && npm install ejs

## 🎮 Быстрый старт за 30 секунд

Создай файл main.is:

echo "Hello World!"
name %= "IronScript"
age %= 25
echo name
echo age

Запусти компилятор:

iscript main.is

Или если глобальная команда не настроена:

python compilator_real/main.py main.is

Результат в build/main.js. Запусти его:

node build/main.js

## 📝 Полный синтаксис

### Вывод данных

echo "текст" — вывод в консоль: console.log("текст")
echo переменная — вывод переменной в консоль
print "текст" — всплывающее окно: alert("текст")

### Работа с переменными

%= — объявление изменяемой переменной
    Пример: x %= 10 → let x = 10

#= — объявление константы (значение "запирается в темницу")
    Пример: PI #= 3.14 → const PI = 3.14

%=% — объявление + вывод в консоль
    Пример: name %=% "Bob" → let name = "Bob"; console.log(name)

^= — переопределение переменной (работает для ВСЕХ типов, кроме констант)
    Пример: x ^= 20 → x = 20

### Полная система типов и защиты

Язык запоминает тип числовых переменных и защищает их от неверных операций.

Объявление:
    x %= 10         — x числовая изменяемая
    PI #= 3.14159   — PI числовая константа

Что можно и нельзя:
    x ^= 5          — ✅ OK: число в числовую
    x ^= "текст"    — ❌ ОШИБКА: строка в числовую нельзя
    PI ^= 5         — ❌ ОШИБКА: константу менять нельзя

Строки ведут себя свободнее:
    y %= "hello"    — y строка
    y ^= "world"    — ✅ OK
    y ^= 15         — ✅ OK: строки можно переопределять любым значением

Никакого let x: number = 10. Просто x %= 10 — и язык сам всё запомнит.

### Функции

Объявление через fun (не function):

fun hello(name) {
    echo "Привет, " + name
}

fun add(a, b) {
    a + b
}

Компилируется в:

function hello(name) {
    console.log("Привет, " + name);
}

function add(a, b) {
    return a + b;
}

### Конструкторы объектов

Способ 1: typeC — полный контроль
Когда нужна своя логика внутри конструктора:

typeC Player(id, name) {
    this.id = id
    this.name = name
    this.score = 0
}

Компилируется в:

function Player(id, name) {
    this.id = id;
    this.name = name;
    this.score = 0;
}

Способ 2: TypeLego — одна строка вместо 7 строк
Быстрый конструктор без логики:

TypeLego User *=* name % email % age % isAdmin

Компилируется в:

function User(name, email, age, isAdmin) {
    this.name = name;
    this.email = email;
    this.age = age;
    this.isAdmin = isAdmin;
}

Сравнение с конкурентами:
    JavaScript — 7 строк
    TypeScript — 5-7 строк
    Python — 6 строк
    Java — 8+ строк
    IScript TypeLego — 1 строка!

## 🔄 Система конца строки — контроль над ;

По умолчанию компилятор автоматически ставит ; в конце строк. Но иногда ; не нужна
(после { и перед }). Для отмены используется маркер n^ в конце строки.

Обычный код (компилятор ставит ; сам):
    x %= 10
    echo "Привет"
→
    let x = 10;
    console.log("Привет");

Код с n^ (компилятор НЕ ставит ;):
    app.get("/", (req, res) => { n^
        res.send("OK") n^
    }) n^
→
    app.get("/", (req, res) => {
        res.send("OK")
    })

Правило простое:
    Нужна ; — ничего не делай (компилятор поставит сам)
    Не нужна ; — поставь n^ в конце строки

## 🎨 HTML режим — пиши интерфейсы прямо в коде

HTML пишется прямо в .is файле между html и html-end.
Компилятор сохранит его в папку build/.

Синтаксис:
    html имя_файла.html
        ... HTML код ...
    html-end

Внутри HTML-режима работает компонент btn:
    btn ТекстКнопки%названиеФункции()

Пример:
    html index.html
        <h1>Моё приложение</h1>
        btn Нажми меня%handleClick()
    html-end

Компилируется в:
    <h1>Моё приложение</h1>
    <button onclick="handleClick()">Нажми меня</button>

ВАЖНО: HTML-режим в активной разработке, возможны баги.
Всегда закрывайте html-end.

## 🖥️ Express команды — сервер без боли

Самый мощный модуль языка. Строит Express-сервер с минимумом кода.

### Инициализация сервера: initS

Одна строка заменяет всё это:
    const express = require('express');
    const app = express();
    const path = require('path');
    const ejs = require('ejs');
    const fs = require('fs');
    app.use(express.static(path.join(__dirname, 'public')));
    app.use(express.urlencoded({ extended: true }));
    app.use(express.json());

Пишете просто:
    initS

### Автоматический рендеринг: renderS

Добавляет функцию renderPage для EJS-шаблонов.
Автоматически подключает fs и ejs.

Синтаксис:
    renderS

Что создаётся автоматически:
    function renderPage(file, data) {
        const html = fs.readFileSync(__dirname + '/views/' + file, 'utf8');
        return ejs.render(html, data);
    }

Константы ejs и fs создавать НЕ нужно — компилятор сам подключит когда надо.

### Запуск сервера: startS

    startS 8080    — запуск на порту 8080
    startS         — запуск на порту 3000 (по умолчанию)

Вывод в консоли при запуске:
    🚀 ЗАПУСК СЕРВЕРА 🚀
    Сервер запущен на порту -> 3000

### Маршруты: get, post, put, delete

Базовый синтаксис (работает сейчас):

    get "/" {
        res.send("OK")
    })

    post "/api/users" {
        res.status(201).json(new_user)
    })

    get "/api/users/:id" {
        user %= users.find(u => u.id == req.params.id)
        if (user) {
            res.json(user)
        } else {
            res.status(404).send("Не найдено")
        }
    })

ВАЖНО: В конце маршрута нужна }) — закрывающая скобка.
Это известная особенность текущей версии парсера.

### Полный рабочий пример сервера (8 строк)

initS
renderS

app.set("view engine", "ejs")
app.set("views", __dirname + "/views")

get "/" {
    res.send(renderPage("index.ejs", { name: "IronScript", version: "2.0", days: 3 }))
})

startS 3000

В EJS-шаблонах доступен стандартный синтаксис:
    <%= name %>        — вывод переменной
    <%= version %>     — вывод версии

### Полный пример REST API

initS

get "/api/users" {
    res.json(users)
})

get "/api/users/:id" {
    user %= users.find(u => u.id == req.params.id)
    if (user) {
        res.json(user)
    } else {
        res.status(404).send("Не найдено")
    }
})

post "/api/users" {
    new_user %= req.body
    users.push(new_user)
    res.status(201).json(new_user)
})

startS 8080

### Нативные команды (в разработке)

Планируется синтаксис без res. и лишних скобок:

get "/api/users" {
    json users
}

post "/api/users" {
    echo "Пользователь создан!"
    send "OK"
}

### Советы по Express с IScript

- initS вызывается один раз в начале файла
- renderS ставится сразу после initS
- startS должен быть в конце после всех маршрутов
- echo работает внутри маршрутов для отладки
- TypeLego удобен для создания моделей данных
- Компилятор напомнит установить зависимости, если их нет

## 💪 Сырой JavaScript

Любой код, не распознанный как команда IScript, пробрасывается как есть.
Можно свободно смешивать IScript и чистый JavaScript:

x %= 10
echo x
console.log("Это чистый JS!")
fetch("/api/data")

Компилируется в:

let x = 10;
console.log(x);
console.log("Это чистый JS!");
fetch("/api/data");

Для сырого JS используй n^ чтобы компилятор не ставил ;:

fetch("/api/data") n^

## 🚨 Частые ошибки и их решение

Ошибка: написал function вместо fun
Решение: пиши fun, это короче и правильно для IScript

Ошибка: написал alert вместо print
Решение: пиши print "текст", это в стиле языка

Ошибка: пытаешься изменить константу через ^=
Решение: константы через #= нельзя менять, создай новую переменную

Ошибка: присваиваешь строку в числовую переменную
Решение: числовые переменные принимают только числа, создай новую строковую

Ошибка: забыл }) в конце маршрута
Решение: get "/" { ... }) — обязательно закрывающая скобка

Ошибка: забыл закрыть HTML-режим
Решение: всегда закрывай блок html-end

Ошибка: компилятор ставит ; там где не надо
Решение: добавь n^ в конец строки

Ошибка: сервер не запускается, ругается на модули
Решение: выполни npm init -y && npm install express && npm install ejs

## 🤔 Для кого этот язык

Отлично подходит:
- Тем, кто устал от let const var function в JavaScript
- Для быстрых прототипов и MVP
- Для обучения программированию (простой синтаксис)
- Для пет-проектов и личных проектов
- Тем, кто хочет классы в одну строку
- Тем, кто ценит лаконичность и читаемость

Не подходит (пока):
- Для огромных enterprise-проектов
- Если нужна вся экосистема npm из коробки
- Если не готовы к особенностям молодого языка
