# 🚀 IronScript (iScript) v2.0

Язык программирования, который компилируется в JavaScript, но пишется как на человеческом. Создан для тех, кто устал от многословности TypeScript и хаоса JavaScript. Меньше букв, больше смысла. Строгая типизация, константы, классы в одну строку. Один раз написал — везде работает.

## 📦 Установка

git clone https://github.com/noyemkaren-ship-it/IScript.git

## 🎮 Быстрый старт за 30 секунд

Создай файл script/main.i:

echo "Hello World!"
name %= "IronScript"
age %= 25
echo name
echo age

Запусти компилятор:

python compilator_real/main.py

Открой build/main.js — готовый JavaScript!

## 📝 Полный синтаксис

### Вывод данных

echo "текст" — вывод в консоль: console.log("текст")
echo переменная — вывод переменной: console.log(переменная)
print "текст" — всплывающее окно: alert("текст")

### Работа с переменными

%= — объявление изменяемой переменной: x %= 10 → let x = 10;
#= — объявление константы: PI #= 3.14 → const PI = 3.14;
%=% — объявление + вывод в консоль: name %=% "Bob" → let name = "Bob"; console.log(name);
^= — переопределение ТОЛЬКО числовых переменных (не констант!): x ^= 20 → x = 20;

### Полная система типов и защиты

Язык запоминает тип переменной и защищает её от неверных операций:

x %= 10 — x объявлена как изменяемая числовая переменная
PI #= 3.14159 — PI объявлена как числовая константа

x ^= 5 — OK: x изменяемая и 5 это число
x ^= "текст" — ❌ ОШИБКА: x числовая, нельзя строку!
PI ^= 5 — ❌ ОШИБКА: PI это константа, нельзя изменить!

y %= "hello" — y объявлена как строка
y ^= 15 — OK: ^= работает только для чисел, для строк игнорируется

Никакого let x: number = 10 или const x = 10. Просто x %= 10 или PI #= 3.14 и язык сам всё запомнит и защитит!

### Функции

fun hello(name) {
    echo "Привет, " + name
}

fun add(a, b) {
    a + b
}

Компилируется в:

function hello(name) {
    console.log("Привет, " + name);
}

function add(a, b) {
    a + b;
}

### Конструкторы объектов

Способ 1: Полный контроль через typeC — когда нужна своя логика внутри конструктора:

typeC Player(id, name) {
    this.id = id;
    this.name = name;
    this.score = 0;
}

Компилируется в:

function Player(id, name) {
    this.id = id;
    this.name = name;
    this.score = 0;
}

Способ 2: Быстрый конструктор TypeLego — одна строка вместо 7 строк кода:

TypeLego User *=* name % email % age % isAdmin

Компилируется в:

function User(name, email, age, isAdmin) {
    this.name = name;
    this.email = email;
    this.age = age;
    this.isAdmin = isAdmin;
}

Сравнение с конкурентами по созданию класса:
JavaScript — 7 строк
TypeScript — 5-7 строк
Python — 6 строк
Java — 8+ строк
IronScript TypeLego — 1 строка!

### Сырой JavaScript

Любой код не распознанный как команда IronScript пробрасывается как есть:

console.log("Это чистый JS!");
let x = 10;
fetch("/api/data");
document.getElementById("app");

## 🛡️ Защита от ошибок (AntiBag)

Компилятор в реальном времени проверяет твой код и выводит цветные подсказки:

❌ ОШИБКА: Использован function вместо fun — пиши fun
❌ ОШИБКА: Использован alert вместо print — пиши print
❌ ОШИБКА: Попытка изменить константу через ^=
❌ ОШИБКА: Попытка присвоить строку в числовую переменную
⚠️ ПРЕДУПРЕЖДЕНИЕ: Возможно не закрыта скобка
⚠️ ПРЕДУПРЕЖДЕНИЕ: Непарное количество кавычек
⚠️ ПРЕДУПРЕЖДЕНИЕ: Переменная не объявлена как числовая

## 🏗️ Архитектура проекта

IScript/
├── compilator_real/
│   ├── main.py — точка входа (запуск компиляции)
│   ├── Lexer.py — лексер + AntiBag (проверка ошибок)
│   ├── Parser.py — парсер (генерация JavaScript)
│   ├── Token.py — модель токена
│   └── tokens.py — хранилище токенов и списки типов
├── script/
│   └── main.i — твой исходный код на IronScript
├── build/
│   └── main.js — скомпилированный JavaScript
└── README.md

Процесс компиляции:
script/main.i → AntiBag (проверка ошибок) → Lexer (токенизация) → Tokens (структура) → Parser (генерация JS) → build/main.js

## 🚨 Частые ошибки и их решение

Ошибка: написал function вместо fun
Решение: пиши fun, это короче и правильнее

Ошибка: написал alert вместо print
Решение: пиши print "текст", это в стиле IronScript

Ошибка: пытаешься изменить константу через ^=
Решение: константы через #= нельзя менять, используй %= если нужно менять

Ошибка: присваиваешь строку в числовую переменную через ^=
Решение: числовые переменные принимают только числа

Ошибка: используешь ^= для строковой переменной
Решение: ^= работает только с числами, для строк используй обычное переопределение или %=
