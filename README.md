## 🚀 IronScript (iScript) v2.0

Язык программирования, который компилируется в JavaScript, но пишется как на человеческом. Создан для тех, кто устал от многословности TypeScript и хаоса JavaScript. Меньше букв, больше смысла. Строгая типизация, константы, классы в одну строку. Один раз написал — везде работает.

git clone https://github.com/noyemkaren-ship-it/IScript.git
cd IScript
pip install colorama pydantic

## 🎮 Быстрый старт за 30 секунд

Создай файл script/main.i:

echo "Hello World!"
name %= "IronScript"
age %= 25
echo name
echo age

Запусти компилятор:

python compilator_real/main.py main.i

Открой build/main.js — готовый JavaScript!

## 📝 Полный синтаксис

### Вывод данных

echo "текст" — вывод в консоль: console.log("текст")
echo переменная — вывод переменной: console.log(переменная)
print "текст" — всплывающее окно: alert("текст")

### Работа с переменными

%= — объявление изменяемой переменной: x %= 10 → let x = 10
#= — объявление константы: PI #= 3.14 → const PI = 3.14
%=% — объявление + вывод в консоль: name %=% "Bob" → let name = "Bob"; console.log(name)
^= — переопределение ТОЛЬКО числовых переменных (не констант!): x ^= 20 → x = 20

### Полная система типов и защиты

Язык запоминает тип переменной и защищает её от неверных операций:

x %= 10 — x объявлена как изменяемая числовая переменная
PI #= 3.14159 — PI объявлена как числовая константа

x ^= 5 — OK: x изменяемая и 5 это число
x ^= "текст" — ❌ ОШИБКА: x числовая, нельзя строку!
PI ^= 5 — ❌ ОШИБКА: PI это константа, нельзя изменить!

y %= "hello" — y объявлена как строка
y ^= 15 — OK: ^= работает только для чисел, для строк игнорируется

Никакого let x: number = 10 или const x = 10. Просто x %= 10 или PI #= 3.14 и язык сам всё запомнит и защитит!

### Функции

fun hello(name) {
    echo "Привет, " + name
}

fun add(a, b) {
    a + b
}

Компилируется в:

function hello(name) {
    console.log("Привет, " + name);
}

function add(a, b) {
    a + b;
}

### Конструкторы объектов

Способ 1: Полный контроль через typeC — когда нужна своя логика внутри конструктора:

typeC Player(id, name) {
    this.id = id
    this.name = name
    this.score = 0
}

Компилируется в:

function Player(id, name) {
    this.id = id;
    this.name = name;
    this.score = 0;
}

Способ 2: Быстрый конструктор TypeLego — одна строка вместо 7 строк кода:

TypeLego User *=* name % email % age % isAdmin

Компилируется в:

function User(name, email, age, isAdmin) {
    this.name = name;
    this.email = email;
    this.age = age;
    this.isAdmin = isAdmin;
}

Сравнение с конкурентами по созданию класса: JavaScript — 7 строк, TypeScript — 5-7 строк, Python — 6 строк, Java — 8+ строк, IronScript TypeLego — 1 строка!

## 🔄 Система конца строки — контроль над ;

По умолчанию компилятор IronScript автоматически добавляет ; в конец каждой строки. Это удобно в 90% случаев. Но иногда ; не нужна — например после { и перед }. Для этого используется маркер n^ в конце строки.

Как это работает:

Обычный код — компилятор сам ставит ;:

x %= 10
echo "Привет"

Компилируется в:

let x = 10;
console.log("Привет");

Код с n^ — компилятор НЕ ставит ;:

app.get("/", (req, res) => { n^
    res.send("OK") n^
}) n^

Компилируется в:

app.get("/", (req, res) => {
    res.send("OK")
})

Если нужна ; — просто поставь её сам:

fetch("/api");
console.log("Готово");

Когда использовать n^:
- После { в функциях, if, for, while
- Перед } когда закрываешь блок
- В конце строк где ; ломает синтаксис

Когда НЕ использовать n^ или ^n разницы нет обсалютна:
- В обычных командах — компилятор сам всё сделает
- Когда нужна ; — просто напиши её руками

Всё просто: хочешь без ; — ставь n^ в конце строки. Хочешь с ; — ничего не делай или поставь сам. Никакой магии!
Но кстати компилятор понимает контекст поэтому тут примеру
html#=Косая кавыка
код
косая ковычка
ОН поймет даже если это функция и вы удобно разделили
app(
name="Что то",
passwprd="Что то но секретное"
) и компилятор поставит ; только после 2 скобки
представьте насколько же это удобно, но
пока это функционал в разработке так что могут быть 
баги поэтому не стесняитесь использовать ^n или n^

## 🎨 HTML режим — пиши интерфейсы прямо в коде

Больше не нужно создавать HTML отдельно! IronScript позволяет писать HTML прямо в .i файле с помощью специального режима.

Синтаксис: html имя_файла.html открывает режим, html-end закрывает. Всё, что между ними, будет сохранено в указанный HTML файл. Компилятор автоматически создаст его в папке build/ при запуске.

Внутри HTML-режима работает специальный компонент btn, который создаёт кнопку с обработчиком. Синтаксис: btn НазваниеКнопки%названиеФункции().

html index.html
    <h1>Моё приложение</h1>
    btn Нажми меня%handleClick()
html-end

Компилируется в:

<h1>Моё приложение</h1>
<button onclick=handleClick()>Нажми меня</button>

Полный пример с сервером:

initS

html index.html
<!DOCTYPE html>
<html>
<head><title>Мой сайт</title></head>
<body>
<h1>Добро пожаловать на IronScript!</h1>
btn Начать%start()
btn Остановить%stop()
</body>
</html>
html-end

app.get("/", (req, res) => { n^
    res.sendFile(path.join(__dirname, "index.html")) n^
}) n^

fun start() {
    echo "Старт!"
}

fun stop() {
    echo "Стоп!"
}

startS 8080

Этот код создаст полноценный HTML файл с двумя кнопками, подключит сервер Express и запустит его на порту 8080. Никаких лишних файлов, никакого ручного написания HTML тегов для кнопок, никакого boilerplate для сервера. Всё в одном файле .i.

## 🖥️ Полный гайд по Express в IronScript

IronScript делает работу с Express максимально простой. Больше не нужно писать тонны boilerplate кода для создания сервера. Вот всё что тебе нужно знать.

### Инициализация сервера

Команда initS автоматически создаёт все необходимые переменные для работы Express:

initS

Эта одна строка заменяет:

const express = require('express');
const app = express();
const path = require('path');

Всё! После initS ты можешь использовать app и path в любом месте кода.

### Запуск сервера

Команда startS запускает сервер на указанном порту:

startS 8080

Если порт не указан, используется порт 3000 по умолчанию. Компилятор сам добавляет app.listen с красивым выводом в консоль.

### Маршруты Express

Ты можешь использовать чистый JavaScript для создания маршрутов Express. IronScript не мешает, а помогает:

initS

app.get("/", (req, res) => { n^
    res.send("Привет от IronScript + Express!") n^
}) n^

app.get("/api/users", (req, res) => { n^
    res.json({name: "IronScript", version: "2.0"}) n^
}) n^

app.post("/api/data", (req, res) => { n^
    echo "Получены данные!"
    res.send("OK") n^
}) n^

startS 8080

Обрати внимание на n^ после { и } — это запрещает компилятору ставить лишние ; которые сломали бы синтаксис Express.

### Отправка HTML файлов

Создай HTML через html-режим и отправь его через Express:

initS

html index.html
<!DOCTYPE html>
<html>
<head><title>Express + IronScript</title></head>
<body>
<h1>Сервер работает!</h1>
btn Нажми меня%handleClick()
</body>
</html>
html-end

app.get("/", (req, res) => { n^
    res.sendFile(path.join(__dirname, "index.html")) n^
}) n^

startS 8080

### Статические файлы

Для обслуживания статических файлов используй чистый JS внутри IronScript:

initS

app.use(express.static("public")) n^

startS 8080

### Обработка параметров маршрута

initS

app.get("/user/:id", (req, res) => { n^
    user_id %= req.params.id
    echo "Запрошен пользователь: " + user_id
    res.send("Пользователь: " + user_id) n^
}) n^

startS 8080

### Middleware

initS

app.use((req, res, next) => { n^
    echo "Запрос получен!"
    next() n^
}) n^

app.get("/", (req, res) => { n^
    res.send("Главная страница") n^
}) n^

startS 8080

### Обработка ошибок

initS

app.get("/", (req, res) => { n^
    try { n^
        throw new Error("Что-то пошло не так") n^
    } catch (error) { n^
        echo "Ошибка: " + error.message
        res.status(500).send("Ошибка сервера") n^
    } n^
}) n^

startS 8080

### Полный пример REST API

initS

TypeLego User *=* id % name % email

users %= []

app.get("/api/users", (req, res) => { n^
    res.json(users) n^
}) n^

app.post("/api/users", (req, res) => { n^
    new_user %= req.body
    users.push(new_user)
    echo "Добавлен пользователь: " + new_user.name
    res.status(201).json(new_user) n^
}) n^

app.get("/api/users/:id", (req, res) => { n^
    user %= users.find(u => u.id == req.params.id)
    if (user) { n^
        res.json(user) n^
    } else { n^
        res.status(404).send("Не найдено") n^
    } n^
}) n^

startS 8080

### Советы по использованию Express с IronScript

Всегда используй n^ после строк с { и } в Express маршрутах чтобы избежать лишних ;
initS нужно вызывать один раз в начале файла
startS запускает сервер — он должен быть в конце после всех маршрутов
Можно смешивать IronScript переменные и Express код свободно
echo работает внутри маршрутов для отладки
Используй TypeLego для быстрого создания моделей данных

### Сравнение с чистым JavaScript

Чистый JS + Express (30+ строк boilerplate):

const express = require('express');
const app = express();
const path = require('path');
app.get('/', (req, res) => {
    res.sendFile(path.join(__dirname, 'index.html'));
});
app.listen(8080, () => {
    console.log('Сервер запущен на порту 8080');
});

IronScript + Express (4 строки):

initS
app.get("/", (req, res) => { n^
    res.sendFile(path.join(__dirname, "index.html")) n^
}) n^
startS 8080

Разница очевидна. IronScript убирает всё лишнее, оставляя только смысл.

## 📄 Работа с файлами

AppHtml — создание HTML файла из JavaScript:

const html = "<p>Ваш HTML код</p>"
AppHtml("index.html", html)

AppApend — дополнение файла в конец:

const запись = "<p>Новая запись</p>"
AppApend("main.html", запись)

Компилятор автоматически добавит нужные импорты fs/promises и path если вы используете AppHtml или AppApend.

## 💪 Сырой JavaScript

Любой код не распознанный как команда IronScript пробрасывается как есть. Это значит ты можешь смешивать IronScript и чистый JavaScript в одном файле:

x %= 10
echo x
console.log("Это чистый JS!")
fetch("/api/data")
document.getElementById("app")

Компилируется в:

let x = 10;
console.log(x);
console.log("Это чистый JS!");
fetch("/api/data");
document.getElementById("app");

Для сырого JS используй n^ если не хочешь чтобы компилятор добавлял ;:

fetch("/api/data") n^

## 🛡️ Защита от ошибок (AntiBag)

Компилятор в реальном времени проверяет твой код и выводит цветные подсказки:

❌ ОШИБКА: Использован function вместо fun — пиши fun
❌ ОШИБКА: Использован alert вместо print — пиши print
❌ ОШИБКА: Попытка изменить константу через ^=
❌ ОШИБКА: Попытка присвоить строку в числовую переменную
⚠️ ПРЕДУПРЕЖДЕНИЕ: Возможно не закрыта скобка
⚠️ ПРЕДУПРЕЖДЕНИЕ: Непарное количество кавычек
⚠️ ПРЕДУПРЕЖДЕНИЕ: Переменная не объявлена как числовая
💡 СОВЕТ: Вместо console.log можно использовать echo

Процесс компиляции: script/main.i → AntiBag (проверка ошибок) → Lexer (токенизация) → Tokens (структура) → Parser (генерация JS) → build/main.js

## 📊 Полная таблица операторов

%= — Объявление переменной — Изменяемая: Да — Защита типа: Да — Пример: x %= 10
#= — Объявление константы — Изменяемая: Нет — Защита типа: Да — Пример: PI #= 3.14
%=% — Объявление + вывод — Изменяемая: Да — Защита типа: Да — Пример: name %=% "Bob"
^= — Переопределение — Изменяемая: Только %= — Защита типа: Только числа — Пример: x ^= 20
n^ — Запрет ; в конце строки — Пример: function test() { n^
echo — Вывод в консоль — Пример: echo "Привет"
print — Всплывающее окно — Пример: print "Важно!"
fun — Объявление функции — Пример: fun main() {
typeC — Конструктор (полный) — Пример: typeC Player(id) {
TypeLego — Конструктор (быстрый) — Пример: TypeLego User *=* id % name
initS — Инициализация сервера — Пример: initS
startS — Запуск сервера — Пример: startS 8080
html — HTML-режим — Пример: html index.html
html-end — Конец HTML-режима — Пример: html-end
btn — Кнопка в HTML — Пример: btn Нажать%go()

## 🚨 Частые ошибки и их решение

Ошибка: написал function вместо fun — Решение: пиши fun, это короче и правильнее
Ошибка: написал alert вместо print — Решение: пиши print "текст", это в стиле IronScript
Ошибка: пытаешься изменить константу через ^= — Решение: константы через #= нельзя менять, используй %= если нужно менять
Ошибка: присваиваешь строку в числовую переменную через ^= — Решение: числовые переменные принимают только числа
Ошибка: используешь ^= для строковой переменной — Решение: ^= работает только с числами, для строк используй обычное переопределение или %=
Ошибка: забыл закрыть HTML-режим — Решение: всегда закрывай html-end после блока HTML кода
Ошибка: компилятор ставит ; там где не надо — Решение: добавь n^ в конец строки чтобы запретить ; например: function test() { n^
Ошибка: нужно несколько команд в одной строке — Решение: пока не поддерживается, пиши каждую команду с новой строки

## 🤔 Для кого этот язык

Отлично подходит: тем кто устал от let const var в JavaScript, тем кто хочет классы в одну строку, для быстрых прототипов и MVP, для обучения программированию (простой синтаксис), для личных проектов и пет-проектов, тем кто ценит лаконичность, для full-stack разработки без фреймворков.

Не подходит: для огромных enterprise-проектов (пока), если нужна экосистема npm из коробки, если нужна поддержка TypeScript-типов в IDE.
