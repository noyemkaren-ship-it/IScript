## 🚀 IScript (iScript) v2.0

Язык программирования, который компилируется в JavaScript, но пишется как на человеческом. Создан для тех, кто устал от многословности TypeScript и хаоса JavaScript. Меньше букв, больше смысла. Строгая типизация, константы, классы в одну строку. Один раз написал — везде работает.

## 📝 Полный синтаксис

### Вывод данных

echo "текст" — вывод в консоль: console.log("текст")
echo переменная — вывод переменной: console.log(переменная)
print "текст" — всплывающее окно: alert("текст")

### Работа с переменными

%= — объявление изменяемой переменной: x %= 10 → let x = 10
#= — объявление константы (значение "запирается в темницу"): PI #= 3.14 → const PI = 3.14
%=% — объявление + вывод в консоль: name %=% "Bob" → let name = "Bob"; console.log(name)
^= — переопределение переменной (работает для ВСЕХ типов, кроме констант): x ^= 20 → x = 20

### Полная система типов и защиты

Язык запоминает тип числовых переменных и защищает их от неверных операций:

x %= 10 — x объявлена как изменяемая числовая переменная
PI #= 3.14159 — PI объявлена как числовая константа

x ^= 5 — OK: x изменяемая и 5 это число
x ^= "текст" — ❌ ОШИБКА: x числовая, нельзя строку!
PI ^= 5 — ❌ ОШИБКА: PI это константа, нельзя изменить!

y %= "hello" — y объявлена как строка
y ^= "world" — OK: ^= работает для всех типов
y ^= 15 — OK: строки можно переопределять любым значением

Никакого let x: number = 10 или const x = 10. Просто x %= 10 или PI #= 3.14 и язык сам всё запомнит и защитит!

### Функции

fun hello(name) {
    echo "Привет, " + name
}

fun add(a, b) {
    a + b
}

Компилируется в:

function hello(name) {
    console.log("Привет, " + name);
}

function add(a, b) {
    a + b;
}

### Конструкторы объектов

Способ 1: Полный контроль через typeC — когда нужна своя логика внутри конструктора:

typeC Player(id, name) {
    this.id = id
    this.name = name
    this.score = 0
}

Компилируется в:

function Player(id, name) {
    this.id = id;
    this.name = name;
    this.score = 0;
}

Способ 2: Быстрый конструктор TypeLego — одна строка вместо 7 строк кода:

TypeLego User *=* name % email % age % isAdmin

Компилируется в:

function User(name, email, age, isAdmin) {
    this.name = name;
    this.email = email;
    this.age = age;
    this.isAdmin = isAdmin;
}

Сравнение с конкурентами по созданию класса: JavaScript — 7 строк, TypeScript — 5-7 строк, Python — 6 строк, Java — 8+ строк, IronScript TypeLego — 1 строка!

## 🔄 Система конца строки — контроль над ;

По умолчанию компилятор IronScript автоматически добавляет ; в конец каждой строки. Это удобно в 90% случаев. Но иногда ; не нужна — например после { и перед }. Для этого используется маркер n^ в конце строки.

Как это работает:

Обычный код — компилятор сам ставит ;:

x %= 10
echo "Привет"

Компилируется в:

let x = 10;
console.log("Привет");

Код с n^ — компилятор НЕ ставит ;:

app.get("/", (req, res) => { n^
    res.send("OK") n^
}) n^

Компилируется в:

app.get("/", (req, res) => {
    res.send("OK")
})

Всё просто: хочешь без ; — ставь n^ в конце строки. Хочешь с ; — ничего не делай или поставь сам. Никакой магии!

## 🎨 HTML режим — пиши интерфейсы прямо в коде

Больше не нужно создавать HTML отдельно! IronScript позволяет писать HTML прямо в .is файле с помощью специального режима.

Синтаксис: html имя_файла.html открывает режим, html-end закрывает. Всё, что между ними, будет сохранено в указанный HTML файл. Компилятор автоматически создаст его в папке build/ при запуске.

Внутри HTML-режима работает специальный компонент btn, который создаёт кнопку с обработчиком. Синтаксис: btn НазваниеКнопки%названиеФункции().

html index.html
    <h1>Моё приложение</h1>
    btn Нажми меня%handleClick()
html-end

Компилируется в:

<h1>Моё приложение</h1>
<button onclick=handleClick()>Нажми меня</button>

ВАЖНО: HTML-режим сейчас в разработке, могут быть баги.

## 🖥️ Express команды — сервер без боли (РЕАЛЬНЫЙ СИНТАКСИС)

ВНИМАНИЕ: Ниже описан АКТУАЛЬНЫЙ синтаксис, проверенный на компиляторе v2.0. 
Из-за особенностей парсера в конце некоторых блоков требуется дополнительная скобка.

### Инициализация сервера

initS

Эта одна строка заменяет:
const express = require('express');
const app = express();
const path = require('path');

### Запуск сервера

startS 8080

Если порт не указан, используется 3000 по умолчанию.

## Подключения атвоматической функции рендаринга
Если написать renderS
тогда автоматический создлатсья вот такая функция
fun renderPage(file, data) {                                          // ← "fun" — невалидный JS!
    html %= fs.readFileSync(__dirname + "/views/" + file, "utf8")    // ← "html %=" — невалидный JS!
    ejs.render(html, data)                                           // ← нет return
}
Пример кода:
initS
renderS

ejs#=require("ejs")
fs#=require("fs")

app.set("view engine", "ejs")
app.set("views", __dirname + "/views")

get "/" {
    res.send(renderPage("index.ejs", { name: "IronScript", version: "2.0", days: 3 }))
})

startS 3000
Также спомощью него вы можете передатьв  html данные и выводить из и взаимодействовать с ними через
{{ переменная }}

### Маршруты (БАЗОВЫЙ СИНТАКСИС — РАБОТАЕТ СЕЙЧАС)

initS

get "/" {
    res.send("OK")
})

startS 8080

Компилируется в:

const express = require('express');
const app = express();
const path = require('path');
app.get("/", (req, res) => {
    res.send("OK")
});
app.listen(8080, () => {
  console.log('🚀 ЗАПУСК СЕРВЕРА 🚀');
  console.log('Сервер запущен на порту -> 8080');
});

ВНИМАНИЕ: Сейчас в конце маршрута нужна }) — закрывающая скобка. Это известная особенность молодого языка.

### Нативные команды (в разработке)

Планируется синтаксис без res. и лишних скобок:

get "/api/users" {
    json users
}

post "/api/users" {
    echo "Пользователь создан!"
    send "OK"
}

Этот синтаксис в активной разработке и будет доступен в следующих версиях.

### Полный рабочий пример REST API

initS

get "/api/users" {
    res.json(users)
})

get "/api/users/:id" {
    user %= users.find(u => u.id == req.params.id)
    if (user) {
        res.json(user)
    } else {
        res.status(404).send("Не найдено")
    }
})

post "/api/users" {
    new_user %= req.body
    users.push(new_user)
    res.status(201).json(new_user)
})

startS 8080

### Советы по использованию Express с IronScript

- initS нужно вызывать один раз в начале файла
- startS запускает сервер — он должен быть в конце после всех маршрутов
- Можно смешивать IronScript переменные и Express код свободно
- echo работает внутри маршрутов для отладки
- Используй TypeLego для быстрого создания моделей данных

## 💪 Сырой JavaScript

Любой код не распознанный как команда IronScript пробрасывается как есть. Ты можешь смешивать IronScript и чистый JavaScript в одном файле:

x %= 10
echo x
console.log("Это чистый JS!")
fetch("/api/data")

Компилируется в:

let x = 10;
console.log(x);
console.log("Это чистый JS!");
fetch("/api/data");

Для сырого JS используй n^ если не хочешь чтобы компилятор добавлял ;:

fetch("/api/data") n^

n^ — Запрет ; в конце строки — Пример: function test() { n^

## 🚨 Частые ошибки и их решение

Ошибка: написал function вместо fun — Решение: пиши fun, это короче и правильнее
Ошибка: написал alert вместо print — Решение: пиши print "текст", это в стиле IronScript
Ошибка: пытаешься изменить константу через ^= — Решение: константы через #= нельзя менять
Ошибка: присваиваешь строку в числовую переменную через ^= — Решение: числовые переменные принимают только числа
Ошибка: забыл }) в конце маршрута — Решение: get "/" { ... }) — нужна закрывающая скобка
Ошибка: забыл закрыть HTML-режим — Решение: всегда закрывай html-end
Ошибка: компилятор ставит ; там где не надо — Решение: добавь n^ в конец строки
